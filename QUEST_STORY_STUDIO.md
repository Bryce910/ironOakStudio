# Valwood Quest & Story Studio

Run [Launch_Valwood_Story_Studio.sh](/home/computer/Desktop/final_engine/Launch_Valwood_Story_Studio.sh), then use the separate [local editor](http://127.0.0.1:8872/).

Build chapters, story beats, quests, objectives and branching dialogue. Rehearse choices and rewards in Preview, save a portable story project, then export native gameplay.

For Windows, extract [the portable package](/home/computer/Desktop/final_engine/Valwood_Quest_Story_Studio_2026-11-02.zip) and open Open_Story_Studio.bat. No Python, Unity or internet is needed. You can also copy [the standalone HTML](/home/computer/Desktop/final_engine/Valwood_Quest_Story_Studio.html) alone.

The included example follows the modern father to Grandstone and plans his later knight chapter. Exported quests need matching scene IDs and a Components manifest. The environment playtest slices currently freeze story logic, so enabling those quests in a playtest is a separate integration step.
