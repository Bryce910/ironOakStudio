# First exercise — a small environment

Allow about thirty minutes. Start in a fresh workcopy and keep the existing presentation route intact.

1. Tour the current arrival area. Practice right-mouse fly controls, wheel zoom and F to frame a selected object.
2. Open **Landscape → Find open ground**. Raise a small hill with a short stroke. Release to build, inspect it, Undo, then Redo.
3. Paint a small grass patch. Paint trees beside it using the separate tree layer. Add low plants; confirm the earlier grass and trees remain.
4. In **Water**, place a small pond on clear ground. Inspect the water and banks from several angles. Select the new pond in Water, resize or move it to clear ground, and confirm its old basin ground restores. Undo and Redo the whole pond.
5. Place one ordinary prop, duplicate it, then use **End** to snap it to terrain. Check its size against the character.
6. Press **Ctrl+Shift+S**, close the editor and reopen the same workcopy. Verify the hill, planting, pond and prop remain.
7. Switch to game view with **F11** and walk around the edits. Test walking against the generated tree trunks and rocks after the build commits. Grass and low plants remain visual.
8. Save and close. Choose **Return Saved Changes** and send the new return folder with a short note describing the edit.

If a brush turns orange, move away from imported floors, foundations, paths or existing water. Keep ponds/rivers fully on clear ground. Report a screenshot and editor log if an operation fails; preserve the workcopy for diagnosis.
