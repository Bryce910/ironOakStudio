# Valwood World Designer — Quality Milestone

Extract the **entire ZIP into a new writable folder**, then run **Valwood World Designer.exe**. Keep every accompanying folder together. Unity and a separate Python installation are unnecessary.

Choose an area and click **Open Editor**. First open verifies that area's reference seed and makes a separate editable workcopy beside the delivery. Later opens reuse that workcopy. **New Workcopy** preserves earlier work and selects a fresh copy. Keep this delivery separate from older deliveries and their work folders.

| Area | What is included |
| --- | --- |
| Castle City & Countryside | Castle, town, streets, surrounding landscape |
| Expanded Jungle | Expanded jungle paths, vegetation and wildlife reference |
| Grandstone Stronghold | Snowy approach, entrance, halls and mountain architecture |
| Apartment & Valois Arrival | Current quality milestone: apartment and arrival camp with the surrounding landscape |

The arrival editor opens at the meadow. This is an environment editor; the separate playable demo starts the story in the apartment. Use the Scene Outliner to select and **F**rame an object when touring.

New apartment/arrival workcopies start with **Balanced** graphics and automatic quality, using a 2048-pixel shadow map and half-resolution reflections. Graphics settings also offer higher presets, including Cinematic. Settings belong to the selected workcopy.

## Build a landscape

Click **Landscape**, then **Find open ground**. Choose **Shape** for hills, **Plant** for vegetation, or **Water** for ponds, lakes and rivers. Drag to paint; release to build. Keep each stroke short while learning. Orange areas are protected imported floors, foundations or routes.

Use the separate vegetation layers to paint grass, trees, rocks or low plants without replacing the other layers. Generated tree trunks and rocks block walking once their committed generation is ready. Grass and low plants remain visual. Test the built result in game view; the painting preview is not the committed collision world.

For a pond or lake, set size/depth and click clear ground once. New ponds can be selected in Water, resized with **Apply basin size**, or moved to a picked clear target; their basin moves with them and the former ground is restored. Deleting or disabling a new pond restores its ground. Legacy baked ponds retain their old carved ground. For a river, place at least two points, then choose **Finish river**. Undo returns the complete operation. **Ctrl+Shift+S** applies and saves.

| Controls | Action |

| Ctrl+C / Ctrl+V / Ctrl+D | Copy / Paste / Duplicate |

Save and close the editor before **Return Saved Changes**. The frontend opens a new return folder; send that folder using your agreed delivery method. **Open Work Folder** locates the saved project. No existing workcopy is reset by this delivery.
