# Start here — world design

Your first session is an orientation: tour the four areas, learn the camera and make one small saved landscape edit. Character creation is outside this assignment.

1. Extract the whole ZIP into a new writable local folder.
2. Run **Valwood World Designer.exe**.
3. Choose **Apartment & Valois Arrival** to see the current milestone, then **Open Editor**.
4. Hold right mouse and use WASD to fly. Use Shift for speed, Ctrl for precision, and the wheel to zoom.
5. Read FIRST_ASSIGNMENT.md and complete its small exercise.

First open installs a pristine reference seed and an independent editable workcopy in `<delivery>_Work`. Allow installation and scene preparation to finish. The frontend checks free space; downloading/extracting a roughly 32 GB bundle and installing a seed plus a workcopy requires additional disk space. Installing all four areas uses substantially more space than installing one.

The new apartment/arrival seed starts with **Balanced** graphics and automatic quality. Open Graphics settings to select another preset, including Cinematic for a more powerful computer. Each workcopy keeps its own saved settings.

Keep the extracted delivery and Seeds unchanged. Work only in Workspaces. Save and close the editor before creating another workcopy or returning changes. **New Workcopy** preserves your existing work. Keep older deliveries in their own folders.

Use **Open Work Folder** to locate the saved project. Use **Return Saved Changes** after saving and closing; it creates a new return folder for owner review.

If startup fails, send the frontend status and `logs/editor-latest.log` from the selected workcopy. The frontend's own logs are under `<delivery>_Work/Logs`.
