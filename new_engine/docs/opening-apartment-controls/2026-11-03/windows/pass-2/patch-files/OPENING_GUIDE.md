# Valwood opening apartment controls and animated TV r5 r2 — Windows

Run **Launch_Opening.bat** in this independent installed seed. Choose **Begin the Journey** to play the modern house → transport → Meadows of Valois opening, or **Continue Checkpoint** after a checkpoint has been saved.

Examine the notebook on the coffee table, approach the front door, then follow the meadow path to the weathered waystone. This refreshed playable sequence uses an improved modern apartment with restrained paint and wood materials, living-room and kitchen dressing, a finished bedroom, a recessed curtained window, practical lights and a revised cinematic opening. The living room also has an animated television game picture, a compact console, two controllers, a remote, game cases and cables. The television runs an original looping platform-adventure animation. An enclosed bathroom beside the bedroom now includes a toilet, sink, mirror, shower fittings, towels and toilet rolls. Its door is parked open for this preview. Existing countryside and neutral opening interactions remain in place. The meadow route is about 92 metres.

## Controls

- WASD moves, mouse looks, Left Shift sprints and Space jumps. Press E to interact.
- Controller: left stick moves, right stick looks, LB/L1 or left-stick click sprints, X/Square jumps and A/Cross interacts.
- Escape or Start/Options pauses. J/Tab or Y/Triangle opens the journal.
- Hold Enter/Space or A/Cross to skip a cinematic.
- F10 or the pause menu opens graphics/display controls. Pause also provides sensitivity, stick deadzone, inverted vertical look and reduced motion.
- Release held sticks after menus or cinematics so ordinary movement can resume safely.

## Room lights and television

Approach a wall switch, aim at its plate and press E / controller A when the room-light prompt appears. Living room, kitchen, bedroom and bathroom circuits switch independently. Window daylight stays independent. Light choices save automatically with the opening checkpoint and restore through Load or Retry. Starting a new journey resets the room lights.

The television plays a real-time eight-second looping pixel adventure with a running/jumping character, moving islands, clouds, pickups and water.

## Checkpoints

F5 saves the current stable story checkpoint, F8 restores it and R restarts it during gameplay. Pause provides the same actions. A checkpoint restores a supported authored position and completed story step, rather than an arbitrary position or a partially completed cinematic. The new seed begins with no saved progress; checkpoint files belong only to its private project/saves folder. Graphics settings also belong to this seed.

The apartment reuses the existing owned furniture set. The bedroom uses the bed asset’s integrated cabinets and lamps; duplicate bedside props have been removed. This refresh improves room composition, surface materials, dressing and lighting.

## Scope and status

This is an opening playthrough in first person. A replacement father body, the armor transformation, equipment progression and combat are outside this pass. The notebook and waystone provide neutral demo interactions; the larger story and cause of the transport remain open for writing.

The current Linux runtime passed the extended 33-check journey/control workflow, including room circuits, supported walking and saved-state behavior. This package includes the newly cross-compiled Windows runtime and matching private project shaders. Windows/Wine compatibility results are recorded separately with the release evidence. Actual Windows graphics-driver and physical-controller rehearsal is still needed on the receiving PC. This package does not certify a frame-rate floor or final AAA visual quality.

All runtime asset references use project-relative paths. The installer creates ordinary independent files, including copied base assets; it does not create symlinks or reuse writable files from artist workspaces. The original Orientation transport, original source projects and earlier playtest seeds are preserved. This seed is for the opening playthrough; use the separate original artist workspace for editing.

If startup fails, keep logs/opening-latest.log. A graphics driver providing OpenGL 3.3 is required. Unity and a separate Python installation are not needed.
