# Valwood opening story r2 — Windows

Run **Launch_Opening.bat** in this independent installed seed. Choose **Begin the Journey** for a fresh playthrough or **Continue Checkpoint** after saving progress.

The father comes home exhausted from working extra shifts and still struggles to pay for ordinary life. Read the bills on the coffee table, then walk to the console beneath the TV. Press **E / controller A** to turn it on. The screen displays **VALOIS / NEW GAME**. Release the interaction button, then press **Enter / controller A** to start a new game. The television triggers the transport into the Meadows of Valois. Follow the meadow path to the waystone; its route is about 92 metres.

## Controls

- WASD moves, mouse looks, Left Shift sprints and Space jumps. Press E to interact.
- Controller: left stick moves, right stick looks, LB/L1 or left-stick click sprints, X/Square jumps and A/Cross interacts.
- At the television menu, Enter or A/Cross starts New Game. Escape or B/Circle steps away without losing bills progress. A held interaction cannot automatically start New Game.
- Escape or Start/Options pauses ordinary gameplay. J/Tab or Y/Triangle opens the journal; the journal retains the bills context.
- Hold Enter/Space or A/Cross to skip a cinematic.
- F10 or pause opens graphics/display controls. Pause also includes sensitivity, deadzone, invert Y and reduced motion.
- Release held sticks after menus/cinematics before moving again.

## Apartment

The apartment includes a living room, kitchen, bedroom, bathroom, gaming corner and four independent room-light switches. Aim at a switch and use E / A when prompted. Window daylight remains independent. The TV begins in standby for this story, changes to a title screen when the console is activated and shows loading/transport effects after New Game.

The bills briefly appear as a readable overlay after inspection and remain available in the journal. Existing furniture is reused; the bathroom door is parked open and the fixtures are decorative.

## Checkpoints

F5 saves the current stable story checkpoint, F8 restores it and R restarts it during gameplay. Pause provides the same actions. Reloading restores a supported authored position and completed story step, rather than an arbitrary pose or a partially played cinematic. Cancelling New Game retains bills progress; a cancelled menu does not start the transport. Room-light choices save with the checkpoint. Begin the Journey resets the opening and lights.

This installed seed begins without saved progress and owns its own graphics settings and project/saves folder. It never shares writable save files with artist workspaces.

## Scope and verification

This pass establishes the playable story cause and cinematic staging. It uses text reactions and existing audio cues, with an animated television title/loading screen. It does not add an acted voice performance, replacement father body, hand/door animations, armor transformation, combat encounter or equipment progression. The meadow waystone remains the end of this opening preview.

The matching runtime/project and acceptance results are recorded separately with this release. CPU bundle verification checks hashes, dependencies and portable paths; a native Windows GPU/audio/physical-controller rehearsal is still required on the receiving PC. This release does not certify a frame-rate floor or final AAA visual quality.

The installer creates ordinary independent files from the verified Orientation base and these explicit patches. Original sources, transport files and earlier releases remain preserved. Use the original separate artist workspace for editing.

If startup fails, keep logs/opening-latest.log. A graphics driver providing OpenGL 3.3 is required. Unity and a separate Python installation are not needed.
