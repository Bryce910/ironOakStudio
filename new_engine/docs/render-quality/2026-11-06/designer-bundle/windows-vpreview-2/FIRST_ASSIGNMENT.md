# First thirty minutes

Goal: learn the existing environments, build a small landscape and return a saved change. Start in **Castle City & Countryside**, using the independent workspace created by the new Landscape delivery.

## 0–5 minutes: tour

Open the city and inspect the town entrance, a street, the castle backdrop and the surrounding meadow. Fly with right mouse + WASD; Q/E changes height. Switch with F11 for a ground-level look. Take one screenshot and write down three environment improvements you would prioritize.

Preview the other area choices when convenient. Close the current editor before opening another. Keep the first exercise in one selected working copy.

## 5–15 minutes: paint a small landscape

1. Click **Landscape** at the top, then **Find open ground**. Capture a before screenshot. Keep the first experiment away from streets and buildings.
2. Select **Shape → Raise**, with Brush width around 32m and modest Strength. Drag a short stroke and release. Wait for the build. Try **Undo landscape**, then Ctrl+Y. Each should restore the whole stroke.
3. Start another stroke and press Escape before releasing. Confirm the previous landscape remains.
4. Select **Plant → Meadow**, choose a 32–64m brush and moderate Density, then paint one small area. Release and allow the grass to stream in. Inspect it from nearby and farther away.
5. Try a small **Forest** patch beside it. Leave a clear walking gap. Watch the painted-area count; overlapping later areas replace the earlier growth mix.
6. Click **Save landscape**. Keep this small result for the reopen check.

Optional next session: select **River**, click three points along gentle open ground, then **Finish river**. Check water and banks; use **Undo landscape** to remove the whole river if it cuts the wrong route. An unfinished river can be corrected with **Undo last point** or discarded with **Cancel river**.

## 15–22 minutes: place, copy and ground

1. Find a clear side area near the initial walkable position, away from doorways, paths and conversation positions. Capture a before screenshot. Editor and player cameras keep separate positions, so F11 does not move the player to the flying camera.
2. Search the Assets/Content Browser for an existing small crate or rock. Drag it into the viewport and wait for the placement notification.
3. Select it and press F to frame it. Try W to move, E to yaw, and R to scale. Use Escape during one gesture to cancel it.
4. Press Ctrl+C, then Ctrl+V three times. Each copy should be visible and selected. Paste uses transformed bounds and a gap to form a row. Find **Edit → Paste settings** if its direction or spacing needs adjustment.
5. Move a copy above the ground, then press End. Confirm the model sits on the terrain. End preserves orientation and scale; it does not flatten the ground.
6. Try Ctrl+Z and Ctrl+Y. Confirm the actual mesh follows the edited state. Frame with F if you lose the selection.
7. Rename or group the practice props so the owner can identify them, for example `Practice_RockRow`.

Use small props for this exercise. A copied city house needs separate collision work before it can become a playable building.

## 22–30 minutes: save, reopen and return

1. Press Ctrl+Shift+S. Wait for Apply and Save to finish. If you used other typed tools, also use **File → Save project checkpoint**.
2. Press F11 and walk around the props. Check their scale, grounding and clearance.
3. Close the editor. In World Designer, click **Open Editor** for the same area. Confirm the landscape, vegetation, props, transforms and names survived reopening. Fly back to the practice area if needed; keep a screenshot or coordinates to find it.
4. Capture the result, close the editor, then click **Return Saved Changes**. Keep the new return folder, screenshot and completed checklist together for delivery.

Optional second exercise: add a continuous preset in **VFX Studio**, frame it, adjust its strength, undo/redo, then remove it. Save and reopen again. Environment polish follows this learning exercise; character authoring is a separate assignment.

Record confusing steps and visible defects with a screenshot and exact reproduction. Your first return is a workflow check and a starting point for discussing the world design priorities.
