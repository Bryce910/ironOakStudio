# Valwood cinematic scenery pass

Keep the native C/C++ OpenGL engine and the map-based 100.8 km world. Build a visible landscape upgrade, retain the original Seldonne project, and verify on the RX 5300 at 1600×900.

1. Select real photographed/scanned CC0 trees, rocks and cliffs; preserve original source provenance and cook bounded GLB variants.
2. Replace the sparse single-detail tree field with clustered forests: detailed nearby trees, simplified middle-distance trees and low-cost distant silhouettes. Keep deterministic roots, staged CPU work, capped instances and shared textures.
3. Shape recognizable mountain ridges and foothills within the existing map geography. Break up grass/soil/rock/snow with actual normal/roughness data and slope-aware materials.
4. Compose golden-hour light, sharper local contact shadows, backlit foliage, atmospheric depth, restrained clouds/water and filmic presentation. Add inspectable scenic destinations without changing ordinary walking speed.
5. Compare actual native captures, validate assets and streaming, and profile continuous forest movement and scenic routes. Document measured frame times and visual limitations; a single pass cannot substantiate a final AAA production-quality claim.
