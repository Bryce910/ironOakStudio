# Native publisher baked lighting

The source renderer's optional glTF attribute is `_VALWOOD_BAKED_LIGHT`, `VEC4` float32. RGB stores **linear decoded diffuse irradiance divided by PI**, before surface albedo, exposure, tone mapping or sRGB encoding. Alpha is validity, normally1 for a valid source lightmap sample and0 for absent or incompatible source data. No additional texture or image sampler is required at runtime.

Both immediate and streamed model loading validate count/type/component format, finite nonnegative HDR RGB up to65504, and alpha0..1. Missing attributes initialize all four values to zero. The shared CPU/GPU static vertex grows from52 to68bytes, with the new stream at byte52. Static VAOs expose it at attribute12. A per-mesh `uBakedLightEnabled` defaults off and resets after imported drawing; pose blending and character variants retain their existing attributes and force baked validity to zero. Other projects' shaders do not opt into this feature.

Only the isolated `valwood_showcase` foliage shaders consume the varying. The original `LightingDataAsset` identifies source sun33431821 as Mixed with `mixedLightingMode=0` (**IndirectOnly**); see `sun-bake.json`. Therefore the native shader replaces the diffuse ambient contribution with source GI and **keeps native diffuse direct sunlight**. Source baked fixtures already contribute direct light to this GI; they should not also be added as duplicate native point lights. Environment specular, native sun specular, new dynamic point lights, material emission and fog remain active.

The vertex shader premultiplies irradiance by validity before interpolation. The fragment shader restores irradiance only for positive validity and blends the diffuse replacement by that weight. This preserves fallback at unbaked vertices without creating dark interpolation borders. Existing material AO and metallic/Fresnel energy conservation apply to the diffuse term; the source irradiance does not receive another global ambient multiplier.

The source converter must sample the original lightmap UV1 and renderer scale/offset before any material UV flip or chunk merge. Unity FULL_HDR decode is raw linear EXR RGB. Directional correction uses the source world normal and `color * (dot(normal, direction.rgb - .5) + .5) / max(direction.a, .0001)` without normalizing the stored direction. Incompatible painted/source mesh UV variants must emit validity0.

`python3 tools/patch_showcase_baked_light.py` reapplies the isolated shader changes and its900m procedural winter vegetation exclusion. `make test-world-model-baked-light` passes with `-Werror`, covering missing/default data, HDR preservation, layout, invalid values and duplicate stream rejection. Native shader/visual validation is a separate required check.
