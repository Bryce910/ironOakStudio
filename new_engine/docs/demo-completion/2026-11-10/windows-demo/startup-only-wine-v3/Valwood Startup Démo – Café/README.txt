LEGENDS OF VALWOOD
A Place at the Fire - Windows Playtest | 10 November 2026

START
Extract the entire ZIP to a writable folder such as C:\Games\Valwood Demo.
Double-click "Valwood Demo.exe". Keep bin and project beside the executable.
Choose BEGIN THE JOURNEY. Allow the first texture/lighting load to finish.
Unity, Python, and the world editor are not needed.

THE OPENING CHAPTER
Apartment -> television NEW GAME -> three travelers at the campfire ->
Bram's loan -> first road fight -> search the body and recover the supplies ->
Rowan's reward -> town and Hugh at the Copper Lantern, who points you toward Mara.
Follow the current objective; the journal records the next step.
This is a work-in-progress playable demo with combat, defeat/retry and saves.

KEYBOARD / MOUSE
WASD move; mouse look; Shift sprint; Space jump/dodge.
E interact/advance dialogue (release between interactions); Enter TV confirmation.
LMB attack; mouse/arrows choose direction; RMB hold directional guard.
Z stows/draws your weapon. V changes first/third person after the loan.
J journal; Esc pause/back.
F5 saves and F8 restores the checkpoint. Inventory and weapon controls are
shown by the game's contextual prompts and pause help.

CONTROLLER
Left stick move. Right stick look while exploring and directional cuts in combat.
Hold LT + right-stick direction for the matching guard. A interact/confirm;
B cancel/dodge; X jump while exploring, X or RT attack in combat.
LB sprint; right-stick click first/third person. D-pad Down stows/draws your weapon.
Menu/Start pause; Y journal. Center the sticks after a menu/focus change.

SAVES / GRAPHICS
Fresh local saves are stored in project\saves, independently of development.
Choose CONTINUE CHECKPOINT to resume. Defeat offers RETRY ENCOUNTER.
Graphics and foliage detail distance are adjustable in Pause/Settings.
The initial Balanced preset adapts resolution. Try higher settings on a faster GPU.

REQUIREMENTS / PLAYTEST NOTES
Windows 10/11 x64 with the GPU vendor driver supporting OpenGL 3.3 core.
Run from the fully extracted writable folder, not inside the ZIP.
Loading and outdoor frame pacing still need work; character art is provisional.
The runtime is cross-built on Linux and tested under Wine. Native Windows GPU,
controller, audio and performance behavior still need a receiving-PC check.
If startup fails, include logs\demo.log when reporting it.
When reporting a bug, include the location, current objective, input device,
expected/actual behavior, graphics preset and a screenshot if available.

Third-party runtime and asset notices are included. This distribution contains
cooked data required to run the demo; it is not an editable asset collection.
