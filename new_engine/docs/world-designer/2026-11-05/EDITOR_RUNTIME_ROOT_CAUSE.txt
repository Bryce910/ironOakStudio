The Jungle editor serialized existing source roots and full transforms with 17-digit precision into a private scene transaction. Its 2,678-record district file grew from 253,907 bytes to at least 283,081 bytes, beyond the loader's old 262,144-byte cap; the ambiguous "Missing or oversized instance file" error was a real size rejection, not a missing Windows temporary path. The editor-only runtime raises the bounded source allowance to 4 MiB while retaining the existing 256-character line, 8,192 base-record, 9,216 prepared-record, 4,096-per-alias, syntax, rooting, and streaming-budget checks. A separate startup condition also rejected every editor opening a project containing opening.config because opening_enabled deliberately excludes editor mode. The private fix explicitly permits editor mode through that condition and preserves every non-editor launch decision. Both changes exist only in the new Windows world-designer runtime; accepted gameplay/demo binaries and canonical engine sources remain unchanged.
