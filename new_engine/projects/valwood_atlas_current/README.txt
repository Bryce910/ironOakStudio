Valwood map terrain project

Launch from the enclosing final_engine folder with Launch_Valwood_World.sh.
Use --landmark seldonne, --landmark callicut or --tour for inspection.
This project has its own assets/map.jpg, captures, imports and saves.
The 100.8 km west/east reference width takes eight hours at 3.5 m/s.
That is a straight uninterrupted width reference, not a timed overland journey.
The original map supplies relative geography; its physical scale is a production decision.
The engine atlas backend supplies the base terrain. The Seldonne village
and its authored sculpt/props/masks remain in their original project.
