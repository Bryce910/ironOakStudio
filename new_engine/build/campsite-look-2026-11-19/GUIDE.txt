Valwood campsite and creek visual review - Linux

Use Launch_Valwood.sh demo, editor, arena, joust or world through the normal
launcher. All modes retain the same accepted native executable and share the
reviewed shader bank. No Windows package is prepared by this pass.

The private review uses the existing purchased BEP vegetation and existing
Poly Haven trees. It changes local woodland composition, a small number of
off-route tree species, shoreline detail and regional weather. Terrain heights,
water footprints, camp NPCs and quest records are preserved. Movement blockers
for the replaced trees are generated by the unchanged production trunk policy.

The shared shader changes correct source-painted bark normal-map frames and
add a bounded river reflection fallback using visible opaque color/depth. The
fallback cannot reconstruct offscreen or occluded scenery. The prior deep-water
swimming and underwater optical branches remain in the accepted executable.

review/FINAL_REVIEW.json records the actual visual acceptance scope, selected
native screenshots, ordinary-input review receipts and performance limits.
review/CHANGESET.json pins the exact scene, shader and test inputs used for
publication. Rejected visual iterations remain retained in the review folder.

This is an incremental running-game scenery update. It is not certification
of AAA quality, a guaranteed match to publisher media or sustained frame rate.
